> 정확히 적은 초안이며, 공개하기 전에 전문가 확인을 받으세요.
> 특히 아래 「짚어야 할 것」의 두 항목은 운영 방식 자체를 정해야 하는 문제입니다.

볼사람은 주선자가 검증해 등록한 사람만 참여하는 비공개 소개팅 서비스입니다.
회원 정보는 **주선자가 대신 등록**하고, 회원은 초대 링크로 들어옵니다.

## 1. 수집하는 정보

### 회원 프로필 (주선자가 등록)

| 구분          | 항목                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| 공개되는 정보 | 성별, 출생연도, 키, 직업·직업군, 회사, 학력, 거주·직장 지역, 종교, MBTI, 흡연, 음주, 취미, 자기소개, 이상형, 사진 |
| **비공개**    | 이름, 연락 방법                                                           |

**이름과 연락 방법은 두 사람이 연결되기 전까지 상대에게 보이지 않습니다.**
목록과 상세 화면에는 `#17` 같은 번호로만 나타납니다.

### 계정

- **회원** — 표시 이름. 비밀번호가 없고, 휴대폰 번호는 받지 않습니다.
- **주선자** — 이메일, 비밀번호(복원 불가능한 형태로만 저장), 이름.

### 이용 기록

- 로그인 세션(브라우저 종류, 마지막 접속 시각)
- 주선자의 주요 작업 기록(무엇을 언제 했는지). **프로필 원문·사진·연락처는 기록에 남기지 않습니다.**

---

## 2. 이용 목적

수집한 정보는 **소개를 성사시키는 데에만** 씁니다.

- 프로필 탐색과 소개 신청
- 두 사람이 서로 수락하면 주선자가 연결
- 주선자의 회원 관리(등록·검토·게시)

광고나 마케팅에 쓰지 않고, 판매하지 않습니다.

---

## 3. 어디까지 보이나

**소속이 곧 공개 범위입니다.**

| 프로필 위치   | 보는 사람                                          |
| ------------- | -------------------------------------------------- |
| 전체공개      | **모든 주선자**. 고치는 것은 등록한 주선자만       |
| 모임 소속     | 그 모임의 주선자만                                 |

회원은 **자기와 같은 쪽** 회원만 봅니다. 전체공개 회원끼리, 모임 회원끼리 각각
서로를 보고 그 경계를 넘지 않습니다.

주선자 가입은 열려 있습니다. **전체공개로 등록된 프로필은 가입한 모든 주선자가 봅니다.**
우리끼리만 관리할 회원은 모임에 등록해야 합니다.

## 4. 외부에 보내는 것

| 받는 곳       | 무엇을                        | 왜                                    |
| ------------- | ----------------------------- | ------------------------------------- |
| OpenAI        | **프로필 원문 텍스트만**      | 항목 자동 추출                        |
| 텔레그램      | 주선자가 봇에 보낸 사진·글    | 주선자가 프로필을 전달하는 통로       |
| 텔레그램      | 신청·수락 알림의 **공개 번호** | 주선자가 처리할 것을 제때 알도록      |
| Cloudflare    | 접속 트래픽                   | 서비스 접속 경로                      |

**사진은 AI에 보내지 않습니다.** 항목을 채우는 근거는 프로필 글뿐이고, 사진은 볼사람
안에만 저장돼 프로필 사진으로 쓰입니다.

**알림에는 이름이 들어가지 않습니다.** 봇이 주선자에게 보내는 신청·수락 알림은
프로필의 공개 번호(예: `40번`)만 담습니다. 누구인지는 볼사람 화면에서만 확인합니다.

**텔레그램은 주선자 전용 통로입니다.** 주선자가 카카오톡에서 받은 프로필을 봇으로
보내면 그 내용이 텔레그램을 거쳐 볼사람에 들어옵니다. 볼사람에 복사된 뒤에는
텔레그램 대화에서 지우시길 권합니다.

## 5. 보관 기간

등록이 끝난 프로필과 사진은 회원이 서비스를 이용하는 동안 보관합니다.
그 밖의 기록은 매일 새벽 4시 10분에 자동으로 정리됩니다.

| 대상                                    | 보관 기간 |
| --------------------------------------- | --------- |
| 로그인 세션(만료·폐기된 것)             | 30일      |
| 초대 링크 기록(사용·만료된 것)          | 90일      |
| **등록되지 않고 방치된 가져오기와 원본 사진** | 30일  |
| AI 모델 원문 응답                       | 14일      |
| 주선자 작업 기록                        | 365일     |
| 봇 연결 코드, 봇 수신 기록              | 7일       |
| 주선자 로그인 실패 기록                 | 14일      |
| 보낸 알림 기록                          | 30일      |
| 데이터베이스 백업                       | 14일      |

로그인 상태는 **30일** 유지되고, 그 뒤에는 주선자에게 링크를 다시 요청합니다.

정리 작업은 **프로필이 사용 중인 사진은 지우지 않습니다.**

데이터를 잃지 않도록 매일 새벽 3시 40분에 데이터베이스 사본을 만들어 14일간 보관합니다.
사본은 서비스가 도는 서버 안에만 두고, 외부 저장소나 다른 업체로 보내지 않습니다.
회원 정보 삭제를 요청하면 운영 중인 데이터에서 곧바로 지우고, 사본에 남은 기록은
보관 기간(14일)이 지나면서 함께 사라집니다.

## 6. 안전하게 지키는 방법

- **사진은 웹에서 직접 열 수 없는 곳**에 둡니다. 화면에 보일 때마다 짧게만 유효한
  주소를 새로 발급하고, 그 주소는 로그인한 사람만 씁니다.
- **데이터베이스가 직접 막습니다.** 응용 프로그램의 실수와 무관하게, 권한 없는 사람은
  다른 모임의 정보를 조회할 수 없습니다.
- 로그인 링크·초대 코드·비밀번호는 **원본을 저장하지 않습니다**(복원 불가능한 형태만).
- 주선자 비밀번호는 15분 안 5회 틀리면 잠시 막힙니다.
- 검색엔진에 노출되지 않습니다.

## 7. 회원의 권리

주선자에게 요청하면 다음을 할 수 있습니다.

- 내 프로필에 무엇이 적혀 있는지 확인
- 잘못된 내용 수정
- 목록에서 감추기(일시중지)
- **삭제** — 프로필과 사진, 계정을 지웁니다

연락처는 주선자에게 문의하세요. 서비스 안에 별도 창구는 아직 없습니다.

## 8. 짚어야 할 것

**아직 정하지 않았고, 서비스를 실제로 열기 전에 정해야 하는 것들입니다.**

### 등록되는 사람의 동의

프로필은 **주선자가 대신 등록**합니다. 등록 시점에 그 사람이 볼사람을 모를 수 있습니다.
주선자가 **본인 동의를 먼저 받아야 하고**, 특히 전체공개로 등록하면 가입한 모든
주선자가 그 프로필을 본다는 사실을 알려야 합니다.

**기록할 자리는 만들었습니다.** 주선자는 확인 방법(카카오톡 대화 / 구두 / 서면)과
확인한 시각을 남기고, 그 기록이 없으면 프로필을 공개할 수 없습니다. 확인 방법과 시각은
남기지만 대화 내용 자체는 저장하지 않습니다.

**아직 정하지 않은 것**은 동의를 받을 때 무엇을 어떤 문구로 알릴지, 그리고 본인이
나중에 동의를 거두면 어떻게 처리할지입니다. 지금은 삭제 요청과 같은 방식으로 주선자에게
연락하는 것 외에 절차가 없습니다.

이 기능이 생기기 전에 등록된 프로필은 **「확인 필요」**로 표시돼 있습니다. 공개 범위를
다시 손대려면 그때 동의를 기록해야 합니다.

### 책임자와 연락처

개인정보 보호책임자, 문의 창구, 사업자 정보가 비어 있습니다.
실제 공개 전에 채워야 합니다.
