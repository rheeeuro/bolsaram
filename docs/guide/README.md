# 볼사람 사용 가이드

> 좋은 사람을, 좋은 방식으로.

볼사람은 **주선자가 검증해 등록한 사람만 참여하는 비공개 소개팅 서비스**입니다.
누구나 가입할 수 있는 서비스가 아니라, 주선자의 초대를 받아야 들어올 수 있습니다.

## 어떤 문서를 보면 되나요

| 문서                      | 대상                      | 내용                                            |
| ------------------------- | ------------------------- | ----------------------------------------------- |
| [회원 가이드](member.md)  | 소개를 받는 분            | 로그인, 프로필 탐색, 마음 보내기, 시그널 확인   |
| [주선자 가이드](admin.md) | 프로필을 등록·연결하는 분 | 가입, 모임(전체공개·모임 소속), 카카오톡 프로필 가져오기, 검토·게시, 초대, 연결 |
| [자주 묻는 질문](faq.md)  | 모두                      | 개인정보 공개 범위, 사진, 계정 문제             |
| [개인정보 처리방침](privacy.md) | 모두                | 무엇을 모으고, 어디까지 보이고, 얼마나 보관하나 |

## 전체 흐름 한눈에 보기

```
주선자                                    회원
──────────────────────────────────       ──────────────────────────────────
가입 (모임은 선택)
        ↓
카카오톡에서 프로필 사진·글 받기
        ↓
Import Inbox 에 올리기
(또는 텔레그램 봇에 보내기)
        ↓
AI 가 항목 자동 정리
        ↓
검토하고 수정
        ↓
공개                              →      프로필 목록에서 발견
        ↓                                        ↓
초대 링크 보내기                  →      로그인하고 내 프로필 연결
                                                 ↓
                                          마음에 드는 분에게 소개 신청
                                                 ↓
                                          상대가 수락
        ↓                                        ↓
신청 목록에서 확인               →       두 사람 연결
        ↓
연결 완료 처리                    →      서로의 이름·연락처 공개
```

## 접속 주소

로컬에서 실행 중이라면 <http://localhost:3020> 입니다.

로그인 화면에서 **회원**과 **주선자** 탭이 나뉘어 있습니다.
