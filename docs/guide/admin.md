# 주선자 가이드

프로필을 등록하고 두 사람을 연결하는 분을 위한 안내입니다.

## 1. 로그인

로그인 화면에서 **주선자** 탭을 고르고 이메일과 비밀번호를 넣습니다.
로그인하면 관리자 화면(`/admin`)으로 들어갑니다.

관리자 화면은 회원 화면과 분리돼 있고, 상단에 다섯 개 메뉴가 있습니다.

| 메뉴         | 하는 일                      |
| ------------ | ---------------------------- |
| 대시보드     | 지금 처리할 일 확인          |
| Import Inbox | 카카오톡 프로필 가져오기     |
| 프로필       | 등록된 프로필 관리·게시      |
| 신청         | 소개 신청 확인, 두 사람 연결 |
| 회원         | 초대 발급, 계정 연결 현황    |

## 2. 대시보드 — 오늘 할 일

네 개 숫자가 보입니다.

- **공개 프로필** — 회원들에게 보이는 프로필 수
- **처리 대기 신청** — 아직 상대가 답하지 않은 신청
- **Import 대기** — 검토가 끝나지 않은 가져오기
- **가입 회원** — 계정을 연결한 회원 수

서로 마음이 닿아 **연결을 기다리는 건**이 있으면 위쪽에 따로 강조됩니다.
그 줄의 링크를 누르면 바로 처리 화면으로 갑니다.

## 3. 카카오톡 프로필 가져오기 (핵심 기능)

**Import Inbox** 에서 합니다. 카카오톡에서 받은 사진과 글을 올리면 AI가 항목을 정리해줍니다.

### 올리는 방법

왼쪽 **새로 가져오기** 패널을 씁니다.

1. **사진** — 카카오톡에서 받은 프로필 사진을 고릅니다. 여러 장 한꺼번에 됩니다.
2. **프로필 글** — 카카오톡에서 복사한 글을 붙여넣습니다.
3. **AI로 프로필 만들기** 를 누릅니다.

사진과 글 중 **하나만 있어도** 진행됩니다.

| 가진 것   | 어떻게 되나                                                             |
| --------- | ----------------------------------------------------------------------- |
| 사진 + 글 | 가장 정확합니다. 글을 우선으로 읽고 사진을 보조로 씁니다                |
| 사진만    | "글도 붙여넣어 달라"고 안내합니다. 사진만으로는 항목을 거의 못 채웁니다 |
| 글만      | 잘 동작합니다. 사진은 나중에 추가할 수 있습니다                         |

- 사진은 장당 **25MB** 까지, JPG·PNG·WebP·HEIC 를 받습니다.
- AI 분석에는 앞쪽 **6장** 까지만 씁니다.

### 검토하기

분석이 끝나면 검토 화면으로 넘어갑니다. 왼쪽에 원본, 오른쪽에 AI가 채운 항목이 나옵니다.

**노란색으로 강조된 항목** 은 확인이 필요하다는 뜻입니다.

- 값이 비어 있는 필수 항목 (성별·출생연도·거주 지역)
- AI 신뢰도가 65% 미만인 항목

각 항목 오른쪽에 신뢰도가 %로 표시됩니다. 고치면 `수정함` 으로 바뀝니다.

> AI가 원문에 없는 내용을 지어내지 않습니다. 모르면 비워둡니다.
> 이름만 보고 성별을 추측하지도 않습니다.

수정한 뒤 **검토 저장** 을 누릅니다.

### 등록하기

두 가지 방법이 있습니다.

- **비공개로 등록** — 프로필만 만들고 회원들에게는 보이지 않습니다. 나중에 공개합니다.
- **등록하고 공개** — 바로 회원들에게 보입니다.

> **확인이 필요한 항목이 남아 있으면 「등록하고 공개」가 잠깁니다.**
> AI 결과가 사람 확인 없이 게시되지 않도록 막아둔 것입니다. 먼저 검토를 끝내주세요.

같은 세션에서 등록 버튼을 여러 번 눌러도 프로필은 하나만 생깁니다.

### 사진 업로드가 실패했다면

검토 화면에서 다시 올릴 수 있습니다. 실패한 사진은 자리에 `업로드 실패` 로 표시됩니다.

## 4. 프로필 관리

**프로필** 메뉴에서 등록된 전체를 봅니다.

### 찾기

- 이름·회사·직업으로 검색하거나 `#17` 처럼 번호로 찾습니다.
- 상태(공개/비활성 등)와 계정 연결 여부로 거를 수 있습니다.

### 상태 바꾸기

프로필 행의 **관리** 를 누르면 상세 화면입니다. 오른쪽에서 상태를 바꿉니다.

| 상태      | 뜻                                   |
| --------- | ------------------------------------ |
| 공개      | 회원 목록에 나옵니다                 |
| 매칭 진행 | 목록에 나오되 진행 중임을 표시합니다 |
| 일시중지  | 목록에서 감춥니다                    |
| 비활성    | 감춥니다. 등록 직후 기본값입니다     |
| 보관      | 더 이상 쓰지 않는 프로필             |

**노출** 은 상태와 별개입니다.

| 노출        | 뜻                                                   |
| ----------- | ---------------------------------------------------- |
| 리스트 노출 | 목록에도 나오고 상세도 열립니다                      |
| 링크 전용   | 목록에는 안 나오고, 링크를 아는 사람만 상세를 봅니다 |
| 비공개      | 주선자 외에는 아무도 못 봅니다                       |

바로 공개하려면 **지금 공개하기** 버튼 하나로 됩니다.

### 내용 수정

같은 화면 왼쪽에서 모든 항목을 고칠 수 있습니다.
**비공개 정보** 칸의 이름과 연락 방법은 **두 사람이 연결된 뒤에만** 상대에게 보입니다.

## 5. 초대 보내기

프로필을 만들었으면 그 주인에게 초대 링크를 보냅니다.

프로필 상세 화면 오른쪽 **계정 연결** 칸에서 **초대 링크 발급** 을 누릅니다.

- 링크는 **발급 직후 한 번만** 화면에 보입니다. 복사해서 카카오톡으로 보내세요.
- 기본 **72시간** 뒤 만료됩니다.
- 새로 발급하면 **기존 링크는 무효** 가 됩니다.
- 한 번 사용된 링크는 다시 쓸 수 없습니다.

**회원** 메뉴에서 전체 초대·연결 현황을 한눈에 봅니다.
전화번호는 가운데를 가려서 표시합니다.

## 6. 신청 처리와 연결

**신청** 메뉴에서 봅니다. 처리할 것이 위로 올라옵니다.

### 상태 흐름

```
신청함 ──상대가 수락──► 수락됨 ──주선자가 연결──► 연결됨 ──► 종료
   │
   ├─ 상대가 거절 ─► 거절됨
   └─ 본인이 취소 ─► 취소됨
```

- **신청함 / 거절됨 / 취소됨** — 주선자가 할 일이 없습니다.
- **수락됨** — 여기서 주선자가 나섭니다.
- **연결됨** — 연결이 끝났습니다. 마무리되면 **종료** 로 바꿉니다.

### 두 사람 연결하기

상태가 **수락됨** 인 건에 **연결하기** 버튼이 있습니다.

1. **연결하기** 를 누릅니다.
2. 두 분께 전달할 안내를 적습니다(선택, 500자까지).
3. **연결 완료** 를 누릅니다.

이 순간부터 **두 사람에게 서로의 이름과 연락 방법이 공개** 됩니다.
적어둔 안내는 양쪽 시그널 화면에 함께 표시됩니다.

> 수락 전에는 연결할 수 없습니다. 상대의 동의 없이 연락처가 오가지 않도록 막아둔 것입니다.

## 7. 지켜야 할 것

- **AI 결과를 그대로 게시하지 마세요.** 사람이 확인한 뒤 공개하는 것이 이 서비스의 전제입니다.
- **이름·연락처는 연결 전까지 공개되지 않습니다.** 비공개 정보 칸에 넣어두세요.
- 프로필 사진은 비공개 저장소에 있고 짧은 시간만 유효한 링크로 전달됩니다.
  링크를 외부에 공유해도 열리지 않습니다.
- 등록되지 않은 사람의 정보를 대신 올릴 때는 **본인 동의**를 먼저 받으세요.

## 8. 자동으로 정리되는 것

매일 새벽 4시 10분에 다음이 정리됩니다.

- 만료된 로그인 세션과 인증번호
- 기한이 지난 초대(자동 회수)
- 오래 방치된 가져오기와 그 원본 사진 — **단, 프로필 사진으로 쓰이는 것은 지우지 않습니다**

등록이 끝난 프로필과 사진은 정리 대상이 아닙니다.
