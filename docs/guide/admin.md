# 주선자 가이드

프로필을 등록하고 두 사람을 연결하는 분을 위한 안내입니다.

## 1. 가입

주선자는 **직접 가입**합니다. 첫 화면의 「주선자로 시작하기」 또는 `/signup` 에서
이름·이메일·비밀번호를 넣습니다. 비밀번호는 10자 이상이어야 합니다.

**가입하면 모임 없이 시작합니다.** 이 상태에서도 바로 일할 수 있습니다 —
전체공개 프로필을 둘러보고, 회원을 전체공개로 등록할 수 있습니다.
텔레그램 봇도 모임 없이 쓸 수 있고, 그렇게 올린 프로필은 전체공개가 됩니다.

## 2. 모임

모임은 **회원을 우리끼리만 관리하고 싶을 때** 만듭니다.

| 프로필 위치     | 누가 보나                                              |
| --------------- | ------------------------------------------------------ |
| **전체공개**    | 모든 주선자가 봅니다. 고치는 것은 **등록한 주선자만**  |
| **모임 소속**   | 그 모임 주선자만 봅니다                                |

- 회원도 **자기와 같은 쪽** 사람만 봅니다. 전체공개 회원끼리, 모임 회원끼리 각각
  서로를 보고, 그 경계를 넘는 소개 신청은 되지 않습니다.
- 한 모임에 주선자가 여러 명 들어갈 수 있습니다. 함께 같은 회원을 관리합니다.
- **한 주선자도 여러 모임에 동시에 속할 수 있습니다.** 단톡방을 여러 개 두는 것과
  같습니다 — 모임마다 회원과 신청이 따로 있고, 서로 섞이지 않습니다.

### 보고 있는 모임 고르기

화면 위쪽, 로고 옆의 **모임 이름 버튼**이 지금 보고 있는 모임입니다. 눌러서 다른
모임으로 옮겨 갑니다.

- **홈·프로필·신청·가져오기·회원이 모두 그 모임의 것만 보여줍니다.** 새로 등록하는
  회원과 가져오는 프로필도 그 모임으로 들어갑니다.
- 목록 맨 위의 **전체공개**도 하나의 방입니다. 여기서는 소속 없는 프로필을 다루고,
  모든 주선자가 같은 것을 봅니다.
- 모임이 하나도 없으면 전체공개만 씁니다.

### 모임 만들기 / 참여

상단 **모임** 메뉴(`/group`)에서 합니다. 이미 모임이 있어도 언제든 더 만들거나
참여할 수 있습니다.

- **만들기** — 모임 이름과 설명(선택)을 넣고 「모임 만들기」. 만든 사람이 개설자입니다.
- **참여** — 동료에게 받은 **초대 코드**를 넣고 「모임 참여」.

만들거나 참여하면 **바로 그 모임을 보게 됩니다.**

### 모임 정보와 동료 초대

같은 화면에 속한 모임이 하나씩 카드로 늘어섭니다. 지금 보고 있는 모임에는
「보는 중」 표시가 붙고, 다른 카드의 「이 모임 보기」로 옮겨 갈 수 있습니다.

- **이름·설명 수정** — 언제든 바꿀 수 있습니다. 설명은 **주선자끼리만** 보는 메모이고
  회원에게는 노출되지 않습니다. 500자까지 씁니다.
- **주선자 목록** — 누가 개설자인지, 회원이 몇 명인지 함께 보입니다.
- **초대 코드 발급** — 「주선자 초대 코드 받기」로 코드를 만들어 전달합니다.
  **24시간·1회용**이고 발급 화면에서 한 번만 보입니다.

### 모임 나가기

각 모임 카드의 **모임 나가기**로 그 모임에서만 나옵니다. 나가면 그 모임의 회원이
보이지 않고, 다시 들어오려면 초대 코드가 필요합니다. 다른 모임은 그대로 남습니다.

- **마지막 주선자인데 회원이 남아 있으면 나갈 수 없습니다.** 나가면 그 회원을 아무도
  볼 수 없게 되기 때문입니다. 회원을 전체공개로 옮기거나 동료를 먼저 초대해 주세요.
- 비어 있는 모임은 나가면서 함께 사라집니다.
- 개설자가 나가면 남은 주선자 중 가장 먼저 들어온 사람이 개설자가 됩니다.
- 보고 있던 모임에서 나가면 남은 모임 중 하나로, 모임이 없으면 전체공개로 옮겨 갑니다.

## 3. 로그인

**주선자 로그인**(`/login`)에서 이메일과 비밀번호를 넣습니다. 이 화면은 주선자
전용입니다 — 회원 입장은 별도 화면(`/enter`)이라 서로 섞이지 않습니다.
로그인하면 볼사람 홈(`/home`)으로 들어갑니다.

비밀번호를 **15분 안에 5번** 틀리면 잠시 로그인이 막힙니다. 15분이 지나면 자동으로
풀리니 기다렸다가 다시 시도하세요. 본인이 틀린 게 아니라면 누군가 시도하고 있다는
뜻이니 비밀번호를 바꿔주세요.

주선자 화면은 회원 화면과 다른 메뉴를 쓰고, 상단에 여섯 개가 있습니다.

| 메뉴     | 하는 일                                 |
| -------- | --------------------------------------- |
| 홈       | 지금 처리할 일 확인                     |
| 프로필   | 등록된 프로필 관리·게시                 |
| 신청     | 소개 신청과 연결 현황 확인              |
| 가져오기 | 카카오톡 프로필 가져오기, 텔레그램 연결 |
| 회원     | 초대 발급, 계정 연결 현황               |
| 모임     | 속한 모임들, 동료 주선자 초대           |

## 4. 홈 — 오늘 할 일

맨 위 한 문장이 지금 가장 급한 것을 알려주고, 그 아래 네 개 숫자가 보입니다.

- **답을 기다리는 신청** — 아직 상대가 답하지 않은 신청
- **가져오기 대기** — 검토가 끝나지 않은 가져오기
- **공개 중인 프로필** — 회원들에게 보이는 프로필 수
- **들어온 회원** — 초대 링크로 들어온 회원 수

숫자를 누르면 해당 화면으로 바로 갑니다.
서로 마음이 닿아 **진행 중인 연결**이 있으면 위쪽에 따로 강조됩니다.

## 5. 카카오톡 프로필 가져오기 (핵심 기능)

**가져오기** 화면에서 합니다. 카카오톡에서 받은 사진과 글을 올리면 AI가 항목을 정리해줍니다.

### 올리는 방법

왼쪽 **새로 가져오기** 패널을 씁니다.

1. **사진** — 카카오톡에서 받은 프로필 사진을 고릅니다. 여러 장 한꺼번에 됩니다.
2. **프로필 글** — 카카오톡에서 복사한 글을 붙여넣습니다.
3. **AI로 프로필 만들기** 를 누릅니다.

사진과 글 중 **하나만 있어도** 진행됩니다.

| 가진 것   | 어떻게 되나                                                    |
| --------- | -------------------------------------------------------------- |
| 사진 + 글 | 정상 동작합니다. 항목은 글에서 채우고, 사진은 프로필 사진이 됩니다 |
| 글만      | 정상 동작합니다. 사진은 나중에 추가할 수 있습니다              |
| 사진만    | **분석할 수 없습니다.** 글을 붙여넣어 달라고 안내합니다        |

- 사진은 장당 **25MB** 까지, JPG·PNG·WebP·HEIC 를 받습니다.

> **사진은 AI 에 보내지 않습니다.** 항목을 채우는 근거는 프로필 글뿐이고,
> 사진은 볼사람 안에만 저장돼 프로필 사진으로 쓰입니다.
> 그래서 사진만 올리면 분석이 되지 않습니다 — 글을 함께 붙여넣어 주세요.

### 텔레그램 봇으로 올리기

볼사람을 열지 않고 **텔레그램 봇에게 보내서** 올릴 수도 있습니다.
카카오톡에서 받은 프로필을 그때그때 넘기기에 편합니다.

#### 처음 한 번: 계정 연결

봇은 누구나 찾을 수 있으므로, 연결된 주선자만 쓸 수 있습니다.

1. **가져오기** 화면 왼쪽 **텔레그램 연결** 칸에서 **연결 코드 받기** 를 누릅니다.
2. 화면에 나온 `/start 코드` 를 봇 대화창에 그대로 보냅니다.
   (**봇 열고 바로 연결하기** 링크를 눌러도 됩니다.)
3. 봇이 「연결됐습니다」라고 답하면 끝입니다.

- 코드는 **발급 직후 한 번만** 화면에 보입니다.
- **15분** 뒤 만료되고, 한 번 쓰면 다시 쓸 수 없습니다.
- 새로 발급하면 기존 코드는 무효가 됩니다.
- 연결을 끊으려면 같은 칸의 **연결 해제** 를 누릅니다. 진행 중이던 등록도 함께 취소됩니다.

#### 프로필 올리기

1. 프로필 **사진** 을 보냅니다. 카카오톡에서 **여러 장을 골라 「공유하기」로 한 번에**
   보내도, 한 장씩 나눠 보내도 **하나의 등록으로 묶입니다.**
   첫 장에서 「사진을 받고 있습니다」라고 한 번만 답하고, 나머지는 조용히 쌓입니다.
   이때 봇이 **어느 모임에 담고 있는지** 함께 알려줍니다 — 봇에는 모임을 고르는
   화면이 없고, 웹에서 지금 보고 있는 모임을 그대로 씁니다.
2. 이어서 **프로필 글** 을 보냅니다. 이때 봇이 **받은 사진 총 장수를 알려줍니다** —
   여기서 장수가 맞는지 확인하세요.
3. 글을 받으면 봇이 바로 분석하고, 끝나면 요약과 **볼사람에서 검토** 버튼을 보냅니다.
   요약 첫 줄에 **담긴 모임** 이 다시 보입니다. 방이 틀렸어도 다시 보낼 필요는
   없습니다 — 검토 화면에서 바꿉니다.

글은 여러 번 나눠 보내도 이어 붙습니다. 사진에 설명을 달아 보내면 글이 없을 때만
프로필 글로 쓰이고, 직접 보낸 글이 항상 우선합니다.
중간에 몇 장 들어왔는지 보려면 `/status` 를 보내세요.

| 봇 명령    | 하는 일                       |
| ---------- | ----------------------------- |
| `/status`  | 지금까지 받은 사진 수와 상태  |
| `/new`     | 새 프로필 등록 시작           |
| `/analyze` | 사진 설명만으로 분석 시작     |
| `/cancel`  | 현재 등록 취소                |
| `/help`    | 사용법                        |

- 사진은 봇으로는 장당 **20MB** 까지 받습니다. 더 큰 사진은 볼사람에서 올려주세요.
- 원본 화질을 그대로 넘기려면 텔레그램에서 **파일로 보내기** 를 씁니다.
- 이미지가 아닌 파일은 받지 않습니다.
- 등록을 시작하고 **24시간** 동안 아무것도 보내지 않으면 그 대화는 만료됩니다.
  받은 사진과 글은 가져오기 목록에 남아 있으니 화면에서 이어서 마무리하면 됩니다.

> 봇으로 올린 것도 **똑같이 검토를 거쳐야 게시됩니다.** 봇이 프로필을 공개하는 일은 없습니다.
> 가져오기 목록의 각 줄에 `텔레그램` 으로 표시됩니다.

### 검토하기

분석이 끝나면 검토 화면으로 넘어갑니다. 왼쪽에 원본, 오른쪽에 AI가 채운 항목이 나옵니다.

오른쪽 맨 위 **등록할 모임** 에서 이 사람을 어느 방에 넣을지 고릅니다.

- 기본값은 가져올 때 보고 있던 모임입니다. 텔레그램으로 받은 것도 같습니다.
- 누르면 바로 저장되고, **그 모임의 가져오기 목록으로 옮겨 갑니다** — 지금 보고 있는
  모임의 목록에서는 사라집니다.
- **전체공개** 로 되돌리는 것은 이 건을 처음 가져온 주선자만 할 수 있습니다.
- 이미 등록한 뒤에는 바꿀 수 없습니다.

**노란색으로 강조된 항목** 은 확인이 필요하다는 뜻입니다.

- 값이 비어 있는 필수 항목 (성별·출생연도·거주 지역)
- AI 신뢰도가 65% 미만인 항목

각 항목 오른쪽에 신뢰도가 %로 표시됩니다. 고치면 `수정함` 으로 바뀝니다.

> AI가 원문에 없는 내용을 지어내지 않습니다. 모르면 비워둡니다.
> 이름만 보고 성별을 추측하지도 않습니다.

수정한 뒤 **검토 저장** 을 누릅니다.

### 등록하기

두 가지 방법이 있습니다.

- **비공개로 등록** — 프로필만 만들고 회원들에게는 보이지 않습니다. 나중에 공개합니다.
- **등록하고 공개** — 바로 회원들에게 보입니다.

> **확인이 필요한 항목이 남아 있으면 「등록하고 공개」가 잠깁니다.**
> AI 결과가 사람 확인 없이 게시되지 않도록 막아둔 것입니다. 먼저 검토를 끝내주세요.

같은 세션에서 등록 버튼을 여러 번 눌러도 프로필은 하나만 생깁니다.

### 사진 업로드가 실패했다면

검토 화면에서 다시 올릴 수 있습니다. 실패한 사진은 자리에 `업로드 실패` 로 표시됩니다.

## 6. 프로필 관리

**프로필** 메뉴에서 등록된 전체를 봅니다.

### 찾기

- 이름·회사·직업으로 검색하거나 `#17` 처럼 번호로 찾습니다.
- 상태(공개/비활성 등)와 계정 연결 여부로 거를 수 있습니다.

### 상태 바꾸기

프로필 카드를 누르면 상세 화면입니다. 오른쪽 **공개 설정** 에서 상태를 바꾸고,
아직 공개 전이면 맨 위 **지금 공개하기** 로 한 번에 올립니다.

| 상태      | 뜻                                   |
| --------- | ------------------------------------ |
| 공개      | 회원 목록에 나옵니다                 |
| 매칭 진행 | 목록에 나오되 진행 중임을 표시합니다 |
| 일시중지  | 목록에서 감춥니다                    |
| 비활성    | 감춥니다. 등록 직후 기본값입니다     |
| 보관      | 더 이상 쓰지 않는 프로필             |

**노출** 은 상태와 별개입니다.

| 노출        | 뜻                                                   |
| ----------- | ---------------------------------------------------- |
| 리스트 노출 | 목록에도 나오고 상세도 열립니다                      |
| 링크 전용   | 목록에는 안 나오고, 링크를 아는 사람만 상세를 봅니다 |
| 비공개      | 주선자 외에는 아무도 못 봅니다                       |

바로 공개하려면 **지금 공개하기** 버튼 하나로 됩니다.

### 내용 수정

같은 화면 왼쪽에서 모든 항목을 고칠 수 있습니다.
**비공개 정보** 칸의 이름과 연락 방법은 **두 사람이 연결된 뒤에만** 상대에게 보입니다.

### 사진 바꾸기

오른쪽 **사진** 칸에서 등록한 뒤에도 사진을 다룹니다.

- **추가** — 파일을 고르면 바로 올라갑니다. 여러 장 한꺼번에 됩니다. 장당 25MB 까지.
- **대표로** — 목록에 보이는 사진을 바꿉니다. 언제든 다시 바꿀 수 있습니다.
- **삭제** — 한 번 더 확인한 뒤 지웁니다. **되돌릴 수 없습니다.**

첫 사진은 자동으로 대표가 되고, 대표를 지우면 남은 것 중 첫 장이 대표가 됩니다.
사진이 있는데 대표가 없는 상태는 생기지 않습니다.

> 사진은 **등록한 주선자만** 바꿀 수 있습니다. 전체공개 프로필이라 다른 주선자에게
> 보이더라도 고치는 것은 등록한 분의 몫입니다.

## 7. 초대 보내기

프로필을 만들었으면 그 주인에게 초대 링크를 보냅니다.
**회원은 아이디·비밀번호를 만들지 않습니다** — 이 링크(또는 입장코드)가 곧 회원의
로그인입니다.

프로필 상세 화면 오른쪽 **본인에게 보내기** 칸에서 **초대 링크 발급** 을 누릅니다.
**초대 링크**와 **입장코드**가 함께 나오고 각각 복사할 수 있습니다.

- 둘은 **같은 것**입니다. 링크를 못 여는 분에게만 코드를 보내세요.
  코드를 받은 분은 첫 화면의 **입장코드로 들어가기**(`/enter`)에 넣습니다.
- **발급 직후 한 번만** 화면에 보입니다. 복사해서 카카오톡으로 보내세요.
- 기본 **72시간** 뒤 만료됩니다.
- 새로 발급하면 **기존 링크와 입장코드는 무효** 가 됩니다.
- 한 번 사용된 링크·코드는 다시 쓸 수 없습니다.

**회원** 메뉴에서 전체 초대·연결 현황을 한눈에 보고, **거기서 바로 발급**할 수도
있습니다. 「초대를 기다리는 분」 목록의 **초대 발급** 을 누르면 그 자리에 링크와
입장코드가 펼쳐집니다. 전화번호는 가운데를 가려서 표시합니다.

복사 버튼을 누르면 **복사됨** 으로 바뀝니다. 바뀌지 않았다면 복사되지 않은 것이니
칸을 눌러 직접 선택해 주세요 — 새로 발급하면 방금 만든 링크가 무효가 됩니다.

## 8. 신청 처리와 연결

**신청** 메뉴에서 봅니다. 처리할 것이 위로 올라옵니다.

### 텔레그램 알림

봇을 연결해 두었다면(5장 「텔레그램 봇으로 올리기」) 이럴 때 알려줍니다.

| 언제                        | 누구에게                                        |
| --------------------------- | ----------------------------------------------- |
| 회원이 요청을 냈을 때       | 그 회원의 담당자 — 확인해야 상대에게 갑니다     |
| 동료가 요청을 보류했을 때   | 그 회원의 담당자 (누른 사람 제외)               |
| 새 신청이 전달됐을 때       | 양쪽 담당자                                     |
| 두 사람이 연결됐을 때       | 양쪽 담당자                                     |
| **신청이 거절됐을 때**      | **신청한 쪽 담당자** (거절을 처리한 사람 제외)  |
| **신청이 취소됐을 때**      | **받는 쪽 담당자** (취소를 처리한 사람 제외)    |

거절·취소·보류를 상대편 담당자에게 알리는 이유는 하나입니다. **거절당한 회원 화면에는
아무 알림도 뜨지 않고** 상대는 목록에서 조용히 사라질 뿐이라, 사정을 말해줄 사람이
필요합니다. 그 사람이 그 회원의 담당 주선자입니다 — 처리한 주선자와 다른 사람일 수
있어서 따로 알립니다.

알림에는 **공개 번호만** 적힙니다(예: `40번 → 23번`). 이름·나이·연락처는 넣지 않습니다.
누구인지는 함께 오는 **신청 목록 열기** 버튼으로 확인합니다.

봇을 연결하지 않았다면 알림이 가지 않습니다 — **신청** 메뉴를 직접 확인해 주세요.

### 상태 흐름

```
신청함 ──상대가 수락──► 연결됨 ──► 종료
   │
   ├─ 상대가 거절 ─► 거절됨
   └─ 본인이 취소 ─► 취소됨
```

- **신청함** — 상대의 답을 기다립니다. 회원이 자기 휴대폰에서 답하면 **확인을
  기다리는 요청**으로 올라오고(아래), 휴대폰을 쓰지 않는 분이면 주선자가 직접
  기록합니다(아래 「본인 대신 처리하기」).
- **거절됨 / 취소됨** — 끝난 건입니다.
  거절됨으로 끝난 사이는 **서로 목록에서 빠지고 어느 쪽도 다시 신청하지 못합니다.**
- **연결됨** — 수락되는 순간 자동으로 여기까지 옵니다. 두 사람에게 서로의 이름과
  연락 방법이 공개된 상태입니다.
- **종료** — 마무리된 건입니다. 이미 공개된 이름과 연락 방법은 그대로 남습니다.

### 회원이 직접 숨긴 것은 보이지 않습니다

회원은 상대를 **숨길** 수 있습니다. 숨기면 서로 목록에서 빠지고 서로 신청도 막힙니다.
**누가 누구를 숨겼는지는 주선자도 볼 수 없습니다** — 신고가 아니라 조용히 넘기는
장치이기 때문입니다. 문제가 있는 회원은 회원이 주선자에게 직접 알려줍니다.

### 확인을 기다리는 요청

회원이 자기 휴대폰에서 누른 것은 **아직 상대에게 가지 않았습니다.** 볼사람에서는
주선자가 사이에서 말을 옮깁니다 — 회원이 누르는 것은 결정이 아니라 요청이고,
주선자가 확인해야 움직입니다.

**신청** 메뉴 맨 위에 **확인을 기다리는 요청** 칸이 뜹니다. 각 줄에 누가 무엇을
요청했는지와, 확인하면 무슨 일이 일어나는지가 함께 적힙니다.

| 요청          | 확인하면                                                     |
| ------------- | ------------------------------------------------------------ |
| 마음 보내기   | 상대에게 신청이 전달됩니다. 그전까지 상대는 아무것도 모릅니다 |
| 수락          | 두 사람이 연결되고 서로의 이름·연락 방법이 공개됩니다         |
| 거절          | 서로 목록에서 빠지고 다시 신청할 수 없습니다                  |
| 신청 취소     | 그 신청이 취소로 닫힙니다                                     |

- **확인하고 전달** — 그대로 진행합니다.
- **보류** — 진행하지 않습니다. 상대에게 전달되지 않습니다.

**보류하면 그 상대는 회원 목록에서 조용히 사라집니다.** 회원 화면에는 아무 알림도
뜨지 않으니 **사정은 주선자가 직접 알려주세요.**

봇 알림은 위 「텔레그램 알림」 표를 보세요 — 요청이 들어올 때와 동료가 보류했을 때
모두 옵니다.

> 수락은 여전히 **본인의 동의**입니다. 회원이 수락하지 않으면 주선자도 연결할 수
> 없습니다. 주선자가 하는 일은 그 답을 옮기는 것이지 대신 정하는 것이 아닙니다.

그 밖에 주선자가 할 일은 두 가지입니다.

- 봇 알림이나 **신청** 메뉴로 연결된 건을 확인하고, 필요하면 두 분께 직접 연락합니다.
- 마무리된 건은 **종료** 버튼으로 정리합니다.

### 휴대폰을 쓰지 않는 분은 대신 둘러봅니다

등록된 분이 자기 휴대폰으로 보기를 꺼리는 경우가 있습니다. 그때는 주선자 폰으로
그분 화면을 열어 함께 봅니다.

1. **프로필** 에서 그분을 열고, 오른쪽 **대신 둘러보기** 칸의
   **이 분으로 둘러보기** 를 누릅니다.
2. 그분이 보게 될 목록이 그대로 열립니다. 마음에 드는 상대에게 **마음 보내기** 까지
   그 자리에서 할 수 있습니다.
3. 화면 아래 띠의 **주선자로 돌아가기** 를 누르면 끝납니다.

- **초대 링크는 소진되지 않습니다.** 주선자 로그인도 그대로 유지됩니다.
- **본인 계정이 연결된 분도 대신 볼 수 있습니다.** 링크를 한 번 열었어도 그 뒤로
  휴대폰을 쓰지 않는 분이 있기 때문입니다. 다만 그분은 같은 화면을 직접 볼 수 있으니,
  **대신 누르기 전에 반드시 물어봐 주세요.**
- 대행은 **주선자가 끝내거나 로그아웃할 때** 끝납니다. 본인이 들어와도 끊기지 않으니
  볼일이 끝나면 띠에서 바로 돌아옵니다.
- 대행 중에 누른 것은 **그분의 이름으로 남습니다.** 누가 대신했는지도 함께 기록됩니다.

### 본인 대신 처리하기

회원에게는 아이디와 비밀번호가 없습니다. 초대 링크를 열어야 들어올 수 있고, 그렇게
만들어진 로그인은 30일 뒤 풀립니다. 그래서 **자기 휴대폰을 쓰지 않는 분은 수락도 거절도
직접 누를 수 없습니다.**

그런 경우 카카오톡이나 대면으로 본인의 답을 확인한 뒤 주선자가 대신 기록합니다.

1. **신청** 메뉴에서 **신청함** 상태의 건을 찾습니다.
2. 카드 아래쪽 **수락 · 거절 · 신청 취소** 중 하나를 누릅니다.
3. 확인 문구를 읽고 한 번 더 누르면 기록됩니다.

| 누르는 것 | 일어나는 일 |
| --------- | ----------- |
| 수락      | 두 사람이 연결되고 서로의 이름·연락 방법이 공개됩니다 |
| 거절      | 서로 목록에서 빠지고 어느 쪽도 다시 신청하지 못합니다 |
| 신청 취소 | 신청한 분이 마음을 거둔 경우입니다. 이 건만 닫힙니다 |

**되돌릴 수 없습니다.** 본인의 답을 확인한 뒤에만 기록하세요. 누가 대신 처리했는지는
기록으로 남습니다.

> 수락 전에는 아무것도 공개되지 않습니다. 상대의 동의 없이 연락처가 오가지 않도록
> 막아둔 것입니다. 주선자가 대신 기록하는 것도 **본인의 답을 옮겨 적는 것**이지
> 주선자가 대신 결정하는 것이 아닙니다.

## 9. 지켜야 할 것

- **AI 결과를 그대로 게시하지 마세요.** 사람이 확인한 뒤 공개하는 것이 이 서비스의 전제입니다.
- **이름·연락처는 상대가 수락하기 전까지 공개되지 않습니다.** 비공개 정보 칸에 넣어두세요.
- 프로필 사진은 비공개 저장소에 있고 짧은 시간만 유효한 링크로 전달됩니다.
  링크를 외부에 공유해도 열리지 않습니다.
- 등록되지 않은 사람의 정보를 대신 올릴 때는 **본인 동의**를 먼저 받으세요.
- **전체공개로 등록하면 모든 주선자가 그 프로필을 봅니다.** 주선자 가입은 누구나
  할 수 있으니, 회원에게 어디까지 공개되는지 미리 알리고 동의를 받으세요.
  우리끼리만 관리할 회원은 모임에 등록하세요.
- **모임 초대 코드를 외부에 흘리지 마세요.** 코드를 가진 사람은 그 모임의 회원 전체를
  보게 됩니다.
- **텔레그램은 주선자 전용 통로입니다.** 회원 계정으로는 연결되지 않고, 회원에게 안내하지
  않습니다. 프로필이 카카오톡 → 텔레그램 → 볼사람을 거치게 되므로, 봇에 보낸 사진과 글은
  볼사람에 복사된 뒤 텔레그램 대화에서 직접 지워주세요.

## 10. 자동으로 정리되는 것

매일 새벽 4시 10분에 다음이 정리됩니다.

- 만료된 로그인 세션
- 기한이 지난 초대(자동 회수)
- 오래 방치된 가져오기와 그 원본 사진 — **단, 프로필 사진으로 쓰이는 것은 지우지 않습니다**
- 방치된 텔레그램 봇 대화(만료 처리)와 다 쓴 연결 코드
- 보낸 알림 기록

등록이 끝난 프로필과 사진은 정리 대상이 아닙니다.
