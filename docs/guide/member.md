# 회원 가이드

소개를 받는 분을 위한 안내입니다. 주선자에게 초대 링크나 입장코드를 받으셨다면 여기서
시작하세요.

## 1. 시작하기

**회원은 아이디도 비밀번호도 만들지 않습니다.** 주선자가 보낸 **초대 링크**나
**입장코드**로만 들어옵니다. 이메일과 비밀번호를 쓰는 것은 주선자뿐입니다.

### 초대 링크로 시작하기

주선자가 회원님의 프로필을 먼저 등록하고 **초대 링크**를 보냅니다.
**이 링크가 로그인입니다** — 비밀번호도, 인증번호도 없습니다.

1. 주선자가 보낸 링크를 엽니다.
2. 어떤 프로필인지(`#17` 같은 번호) 확인합니다.
3. **내 프로필로 시작하기** 를 누릅니다.

누르는 순간 계정이 만들어지고 바로 들어갑니다. 이후 프로필 탐색과 소개 신청을
할 수 있습니다.

> 링크는 **한 번만** 쓸 수 있고 기본 72시간 뒤 만료됩니다.
> 만료됐거나 이미 쓴 링크라면 주선자에게 다시 요청하세요.

### 입장코드로 시작하기

링크가 열리지 않거나 코드만 받으셨다면 코드로 들어옵니다. **링크와 입장코드는 같은
것**이라 하나를 쓰면 다른 하나도 함께 무효가 됩니다.

1. 첫 화면에서 **입장코드로 들어가기** 를 누릅니다(`/enter`).
2. **입장코드** 칸에 받은 코드를 넣습니다. **붙여넣기** 버튼을 쓰면 복사해 둔 코드가
   바로 들어갑니다. 링크 전체를 붙여넣어도 됩니다.
3. **들어가기** 를 누르고, 프로필을 확인한 뒤 시작합니다.

이 화면은 회원용이라 **입장코드 하나만** 묻습니다. 이메일·비밀번호 칸은 없습니다.

> 코드가 길어서 손으로 옮겨 적으면 틀리기 쉽습니다. **복사해서 붙여넣는 것**을
> 권합니다. 틀렸다면 넣은 값이 그대로 남으니 고쳐서 다시 넣으면 됩니다.
> 그래도 안 되면 주선자에게 새로 요청하세요.

### 다시 로그인하기

로그인 상태는 **30일** 유지됩니다. 그 뒤에는 **주선자에게 링크를 다시 요청**하세요.
받은 링크를 열면 그대로 들어갑니다.

- 회원은 아이디·비밀번호가 없습니다. 외울 것도, 잃어버릴 것도 없습니다.
- 문자(SMS)는 보내지 않습니다. 링크와 코드는 주선자가 카카오톡으로 직접 전달합니다.
- 무엇을 모으고 어디까지 보이는지는 **개인정보 처리방침**에 있습니다. 첫 화면과
  로그인·입장 화면, 「내 프로필」 화면 아래 링크에서 로그인 없이도 볼 수 있습니다.

> **링크와 입장코드를 다른 사람에게 전달하지 마세요.** 그것을 가진 사람이 회원님
> 계정으로 들어갈 수 있습니다. 볼사람은 비공개 서비스라 초대받은 분만 들어옵니다.

## 2. 프로필 둘러보기 — 홈

하단 탭의 **홈** 이 프로필 목록입니다.

### 성별 탭과 필터

- 위쪽에서 **전체 / 남성 / 여성** 을 고를 수 있습니다.
- 오른쪽 **필터** 를 누르면 조건 설정 창이 올라옵니다.

조건은 다음과 같습니다.

| 조건   | 기본값                                     |
| ------ | ------------------------------------------ |
| 나이   | 전체 (20 – 55세 안에서 고릅니다)           |
| 키     | 전체 (145 – 200cm 안에서 고릅니다)         |
| 지역   | 전체 (서울·경기·인천 등 광역 단위)         |
| 직업군 | 전체 (IT·금융·전문직·의료·교육 등)         |
| 종교   | 전체 (무교·기독교·천주교·불교·원불교·기타) |
| 흡연   | 전체 (비흡연·가끔·흡연)                    |
| 음주   | 전체 (안 함·가끔·사회적 음주·즐김)         |

나이와 키는 손잡이 두 개를 각각 옮깁니다. 손잡이를 **양끝에 두면 그 조건은 걸리지
않습니다** — 그래서 처음에는 「전체」로 표시되고 모든 분이 나옵니다.
한쪽만 옮기면 「30세 이상」, 「38세 이하」 처럼 그쪽만 걸립니다.
지금 실제로 걸린 조건이 항상 오른쪽에 그대로 적힙니다.

키 조건을 걸면 **키가 적혀 있지 않은 분은 나오지 않습니다.** 조건을 좁히면 그 안내가
시트에 함께 표시됩니다.

조건을 바꾸면 버튼에 **몇 명이 나오는지** 미리 표시됩니다.
너무 좁으면 결과가 없을 수 있으니 **초기화** 로 되돌릴 수 있습니다.

### 목록에서 보이는 것

목록에는 이 정도만 나옵니다.

- 익명 번호 (`#17`)
- 대표 사진 한 장
- 출생연도, 키
- 직업군, 사는 지역(광역 단위)

**이름·회사·연락처는 목록에 나오지 않습니다.**

### 목록 · 사진 두 가지 보기

필터 왼쪽의 작은 버튼 두 개로 보는 방식을 바꿉니다.

- **목록** — 작은 사진 옆에 번호·출생연도·키·직업군·지역이 한 줄로 붙습니다.
  여러 분을 위아래로 훑어볼 때 편합니다. 처음에는 이쪽으로 열립니다.
- **사진** — 사진을 크게 깔아 보여줍니다. 얼굴 위주로 볼 때 고르세요.

고른 방식은 이 기기에 기억되어 다음에 들어와도 그대로 열립니다.
어느 쪽이든 **보이는 내용은 같습니다** — 사진만 크고 작아집니다.

### 관심 담기

목록의 하트를 누르면 **관심** 탭에 저장됩니다(목록 보기는 오른쪽 끝, 사진
보기는 사진 오른쪽 위). 상대는 회원님이 관심을 눌렀다는 사실을 알 수 없습니다.

## 3. 프로필 상세 보기

목록에서 한 사람을 누르면 자세한 내용이 열립니다.

- 사진 여러 장 (아래 점을 눌러 넘김)
- 직업·회사·학력·지역
- 종교, MBTI, 흡연, 음주
- 취미
- 자기소개
- 이상형

여기서도 **이름과 연락처는 보이지 않습니다.** 두 분이 연결된 뒤에 공개됩니다.

## 4. 마음 보내기 (소개 신청)

상세 화면 아래 **소개 신청하기** 를 누릅니다.

1. 확인 창이 뜹니다. 짧은 인사를 남길 수 있습니다(선택, 200자까지).
2. **주선자에게 보내기** 를 누릅니다. 이때 상대에게 바로 가지 않습니다 —
   먼저 **주선자에게 전달**되고 「주선자에게 전했습니다」 화면이 뜹니다.
3. 주선자가 확인하면 그때 상대에게 신청이 전달됩니다.
4. 상대가 수락하고 주선자가 그것까지 확인하면 **두 분이 연결됩니다.**
   서로의 이름과 연락 방법이 열립니다.

> **볼사람에서는 주선자가 사이에서 말을 옮깁니다.** 회원님이 누르는 것은 결정이 아니라
> 요청이고, 주선자가 확인해야 상대에게 갑니다. **확인 전까지 상대는 아무것도 알지
> 못합니다.** 좋은 사람을, 좋은 방식으로 잇기 위한 절차입니다.

주선자가 보내지 않는 편이 낫다고 판단하면 **그분은 목록에서 조용히 사라집니다.**
화면에 따로 알림이 뜨지는 않고, 사정은 주선자가 직접 알려드립니다.

### 알아두실 점

- 같은 분에게 **동시에 두 번** 신청할 수 없습니다. 진행 중인 신청이 끝나야 다시 보낼 수 있습니다.
- 자기 자신에게는 신청할 수 없습니다.
- 상대가 먼저 회원님께 마음을 보낸 상태라면, 신청 대신 **받은 시그널에서 수락** 하시면 됩니다.
- 프로필이 아직 연결되지 않았다면 버튼이 `프로필 연결 후 가능` 으로 표시됩니다.
- **한 번 거절된 사이에는 다시 신청할 수 없습니다.** 회원님이 거절한 분에게도, 회원님을
  거절한 분에게도 마찬가지입니다.
- 숨긴 분에게도 보낼 수 없습니다.
- 이 경우 버튼이 `지금은 보낼 수 없어요` 로 표시됩니다. **어느 이유인지는 화면에 적지
  않습니다** — 이유를 구분해 보여주면 상대가 숨겼다는 사실이 드러나기 때문입니다.

## 5. 시그널 — 주고받은 마음 확인

하단 탭의 **시그널** 에서 세 가지를 봅니다.
답하지 않은 신청이 있으면 **시그널 탭에 숫자**가 붙습니다.

### 받은

누군가 회원님께 마음을 보낸 목록입니다.

- **수락하기** — 「수락을 전했습니다」 화면이 뜹니다. 수락도 **주선자를 거칩니다** —
  주선자가 확인하면 두 분이 연결되고 그때 상대의 이름과 연락 방법이 열립니다.
- **정중히 거절** — 거절도 주선자가 확인한 뒤 상대에게 전달됩니다. 거절로 끝난 뒤에는
  **서로 탐색 목록에서 빠지고, 어느 쪽도 다시 신청할 수 없습니다.**
  같은 분에게 반복해서 답하지 않아도 됩니다.

수락이 곧 회원님의 동의라는 점은 그대로입니다. **회원님이 수락하지 않으면 주선자도
연결할 수 없습니다.** 달라지는 것은 그 답이 주선자를 거쳐 전달된다는 점뿐입니다.

### 보낸

회원님이 신청한 목록입니다. 상대가 답하기 전이라면 **신청 취소** 를 할 수 있습니다.

### 이어짐

수락으로 이어진 인연입니다.

| 표시   | 뜻                                                        |
| ------ | --------------------------------------------------------- |
| 연결됨 | 서로 마음이 닿았습니다. 상대의 이름과 연락 방법이 열립니다 |
| 종료   | 주선자가 이 건을 마무리했습니다. 연락 방법은 계속 보입니다 |

주선자가 남긴 안내가 있으면 함께 표시됩니다.

## 6. 보고 싶지 않은 분 숨기기

프로필 상세 화면 아래의 **이 분 숨기기** 를 누릅니다. 한 번 더 확인한 뒤 적용됩니다.

숨기면 이렇게 됩니다.

- **서로** 탐색 목록에 보이지 않습니다.
- **서로** 마음을 보낼 수 없습니다.
- **상대에게는 알리지 않습니다.** 주선자도 누가 누구를 숨겼는지 볼 수 없습니다.

### 숨길 수 없는 경우

- **진행 중인 신청이 있는 분** — 먼저 신청을 **거절하거나 취소** 한 다음 숨기세요.
  거절하면 그것만으로도 서로 목록에서 빠지고 다시 신청할 수 없게 됩니다.
- **이미 연결된 분** — 연락처를 이미 주고받은 뒤라 화면에서 지우는 것으로 정리되지
  않습니다. 주선자에게 알려주세요.

관심 목록에 담아둔 분을 숨기면 **관심 목록에서도 빠집니다.** 숨김을 해제하면 다시
나타납니다.

### 숨김 해제

**내 프로필 → 숨긴 사람** 에서 목록을 봅니다. 카드를 열어 **숨김 해제** 를 누르면
원래대로 돌아옵니다.

## 7. 내 프로필

하단 탭의 **내 프로필** 에서 등록된 내용을 확인합니다.

- 사진, 기본 정보, 자기소개
- 현재 상태 (공개 / 매칭 진행 / 일시중지 등)

**회원이 직접 수정할 수는 없습니다.** 고칠 내용이 있으면 주선자에게 알려주세요.
사진과 소개는 주선자가 관리합니다.

**숨긴 사람** 목록으로 가는 입구도 이 화면에 있습니다.

로그아웃도 이 화면 아래에 있습니다. 누르면 **한 번 더 확인**합니다 —
로그아웃하면 다시 들어오려면 주선자에게 **새 초대 링크나 입장코드**를 받아야 합니다.

## 8. 내 정보는 어디까지 공개되나요

단계적으로만 열립니다.

| 단계    | 상대에게 보이는 것                                                          |
| ------- | --------------------------------------------------------------------------- |
| 목록    | 익명 번호, 대표 사진, 출생연도, 키, 직업군, 광역 지역                       |
| 상세    | 위 + 사진 전체, 직업·회사·학력, 종교·MBTI·흡연·음주, 취미, 자기소개, 이상형 |
| 연결 후 | 위 + **이름, 연락 방법** (상대가 내 신청을 수락한 뒤)                       |

- 로그인하지 않은 사람은 **아무 프로필도** 볼 수 없습니다.
- 사진은 짧은 시간만 유효한 링크로 전달되며, 링크를 복사해 다른 곳에 붙여도 열리지 않습니다.
- 검색엔진에 노출되지 않습니다.

## 문제가 생겼을 때

| 상황                                     | 해결                                                |
| ---------------------------------------- | --------------------------------------------------- |
| "만료되었거나 이미 사용된 링크입니다"    | 주선자에게 링크를 다시 요청                         |
| "이미 다른 계정에 연결된 프로필입니다"   | 한 계정에 프로필 하나만 연결됩니다. 주선자에게 문의 |
| 프로필 내용이 틀림                       | 주선자에게 수정 요청                                |
