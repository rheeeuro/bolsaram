# 회원 가이드

소개를 받는 분을 위한 안내입니다. 주선자에게 초대 링크를 받으셨다면 여기서 시작하세요.

## 1. 시작하기

### 초대 링크로 내 프로필 연결하기

주선자가 회원님의 프로필을 먼저 등록하고 초대 링크를 보냅니다.
링크를 열면 어떤 프로필인지(`#17` 같은 번호) 확인할 수 있습니다.

1. 초대 링크를 엽니다.
2. **로그인하고 계속하기** 를 누릅니다.
3. 초대받은 휴대폰 번호로 로그인합니다.
4. **내 프로필로 연결하기** 를 누릅니다.

연결이 끝나면 프로필 탐색과 소개 신청을 할 수 있습니다.

> 초대 링크는 **한 번만** 쓸 수 있고 기본 72시간 뒤 만료됩니다.
> 만료됐거나 이미 사용된 링크라면 주선자에게 다시 요청하세요.

### 로그인

휴대폰 번호로 로그인합니다. 비밀번호는 없습니다.

1. 로그인 화면에서 **회원** 탭을 선택합니다.
2. 휴대폰 번호를 넣고 **인증번호 받기** 를 누릅니다.
3. 받은 6자리 숫자를 입력합니다.

- 인증번호는 **5분** 동안 유효합니다.
- 다시 받으려면 **30초** 기다려야 합니다.
- **5번** 틀리면 그 번호는 무효가 되고 새로 받아야 합니다.
- 로그인 상태는 **30일** 유지됩니다.

> 초대받지 않은 번호로는 로그인할 수 없습니다. 볼사람은 비공개 서비스입니다.

## 2. 프로필 둘러보기 — 홈

하단 탭의 **홈** 이 프로필 목록입니다.

### 성별 탭과 필터

- 위쪽에서 **전체 / 남성 / 여성** 을 고를 수 있습니다.
- 오른쪽 **필터** 를 누르면 조건 설정 창이 올라옵니다.

조건은 다음과 같습니다.

| 조건   | 기본값                                     |
| ------ | ------------------------------------------ |
| 나이   | 25 – 38세                                  |
| 키     | 150 – 195cm                                |
| 지역   | 전체 (서울·경기·인천 등 광역 단위)         |
| 직업군 | 전체 (IT·금융·전문직·의료·교육 등)         |
| 종교   | 전체 (무교·기독교·천주교·불교·원불교·기타) |
| 흡연   | 전체 (비흡연·가끔·흡연)                    |
| 음주   | 전체 (안 함·가끔·사회적 음주·즐김)         |

조건을 바꾸면 버튼에 **몇 명이 나오는지** 미리 표시됩니다.
너무 좁으면 결과가 없을 수 있으니 **초기화** 로 되돌릴 수 있습니다.

### 목록에서 보이는 것

카드에는 이 정도만 나옵니다.

- 익명 번호 (`#17`)
- 대표 사진 한 장
- 출생연도, 키
- 직업군, 사는 지역(광역 단위)

**이름·회사·연락처는 목록에 나오지 않습니다.**

### 관심 담기

카드 오른쪽 위 하트를 누르면 **관심** 탭에 저장됩니다.
상대는 회원님이 관심을 눌렀다는 사실을 알 수 없습니다.

## 3. 프로필 상세 보기

카드를 누르면 자세한 내용이 열립니다.

- 사진 여러 장 (아래 점을 눌러 넘김)
- 직업·회사·학력·지역
- 종교, MBTI, 흡연, 음주
- 취미
- 자기소개
- 이상형

여기서도 **이름과 연락처는 보이지 않습니다.** 두 분이 연결된 뒤에 공개됩니다.

## 4. 마음 보내기 (소개 신청)

상세 화면 아래 **소개 신청하기** 를 누릅니다.

1. 확인 창이 뜹니다. 짧은 인사를 남길 수 있습니다(선택, 200자까지).
2. **마음 보내기** 를 누르면 상대에게 회원님의 프로필이 전달됩니다.
3. 상대가 수락하면 주선자가 두 분을 연결해드립니다.

### 알아두실 점

- 같은 분에게 **동시에 두 번** 신청할 수 없습니다. 진행 중인 신청이 끝나야 다시 보낼 수 있습니다.
- 자기 자신에게는 신청할 수 없습니다.
- 상대가 먼저 회원님께 마음을 보낸 상태라면, 신청 대신 **받은 시그널에서 수락** 하시면 됩니다.
- 프로필이 아직 연결되지 않았다면 버튼이 `프로필 연결 후 가능` 으로 표시됩니다.

## 5. 시그널 — 주고받은 마음 확인

하단 탭의 **시그널** 에서 세 가지를 봅니다.

### 받은

누군가 회원님께 마음을 보낸 목록입니다.

- **수락하기** — 서로 마음이 닿습니다. 주선자가 연결을 준비합니다.
- **정중히 거절** — 상대에게 거절로 표시됩니다.

### 보낸

회원님이 신청한 목록입니다. 상대가 답하기 전이라면 **신청 취소** 를 할 수 있습니다.

### 연결됨

수락 이후 단계의 인연입니다.

| 표시   | 뜻                                                               |
| ------ | ---------------------------------------------------------------- |
| 수락됨 | 서로 마음이 닿았고, 주선자가 연결을 준비 중입니다                |
| 연결됨 | 주선자가 연결을 마쳤습니다. 상대의 이름과 연락 방법이 공개됩니다 |
| 종료   | 주선자가 이 건을 마무리했습니다                                  |

주선자가 연결하면서 남긴 안내가 있으면 함께 표시됩니다.

## 6. 내 프로필

하단 탭의 **내 프로필** 에서 등록된 내용을 확인합니다.

- 사진, 기본 정보, 자기소개
- 현재 상태 (공개 / 매칭 진행 / 일시중지 등)

**회원이 직접 수정할 수는 없습니다.** 고칠 내용이 있으면 주선자에게 알려주세요.
사진과 소개는 주선자가 관리합니다.

로그아웃도 이 화면 아래에 있습니다.

## 7. 내 정보는 어디까지 공개되나요

단계적으로만 열립니다.

| 단계    | 상대에게 보이는 것                                                          |
| ------- | --------------------------------------------------------------------------- |
| 목록    | 익명 번호, 대표 사진, 출생연도, 키, 직업군, 광역 지역                       |
| 상세    | 위 + 사진 전체, 직업·회사·학력, 종교·MBTI·흡연·음주, 취미, 자기소개, 이상형 |
| 연결 후 | 위 + **이름, 연락 방법**                                                    |

- 로그인하지 않은 사람은 **아무 프로필도** 볼 수 없습니다.
- 사진은 짧은 시간만 유효한 링크로 전달되며, 링크를 복사해 다른 곳에 붙여도 열리지 않습니다.
- 검색엔진에 노출되지 않습니다.

## 문제가 생겼을 때

| 상황                            | 해결                                                |
| ------------------------------- | --------------------------------------------------- |
| 인증번호가 안 옴                | 30초 뒤 다시 요청. 계속 안 되면 주선자에게 문의     |
| "초대된 번호가 아닙니다"        | 주선자에게 등록된 번호를 확인                       |
| 초대 링크가 만료됨              | 주선자에게 새 링크 요청                             |
| "이미 연결된 프로필이 있습니다" | 한 계정에 프로필 하나만 연결됩니다. 주선자에게 문의 |
| 프로필 내용이 틀림              | 주선자에게 수정 요청                                |
