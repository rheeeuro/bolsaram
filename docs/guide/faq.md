# 자주 묻는 질문

## 가입과 계정

**아무나 가입할 수 있나요?**
아니요. 주선자가 프로필을 등록하고 초대 링크를 보낸 분만 들어올 수 있습니다.
초대받지 않은 번호로는 로그인 자체가 되지 않습니다.

**비밀번호가 없나요?**
회원은 휴대폰 번호와 인증번호로만 로그인합니다. 주선자만 이메일·비밀번호를 씁니다.

**인증번호가 오지 않아요.**
30초 뒤에 다시 요청할 수 있습니다. 계속 받지 못하면 주선자에게 등록된 번호가 맞는지 확인하세요.

**한 계정에 프로필을 여러 개 연결할 수 있나요?**
아니요. 한 계정에 프로필 하나입니다.

**로그인은 얼마나 유지되나요?**
30일입니다. 직접 로그아웃하면 그 즉시 끊깁니다.

## 개인정보

**제 이름과 연락처는 언제 공개되나요?**
주선자가 두 분을 **연결 완료** 처리한 뒤에만 공개됩니다.
상대가 신청을 수락한 시점에도 아직 공개되지 않습니다.

**목록에서는 무엇이 보이나요?**
익명 번호(`#17`), 대표 사진, 출생연도, 키, 직업군, 광역 지역까지입니다.
이름·회사·연락처는 나오지 않습니다.

**로그인하지 않은 사람도 프로필을 볼 수 있나요?**
아니요. 하나도 볼 수 없습니다.

**사진이 인터넷에 돌아다닐 수 있나요?**
사진은 비공개 저장소에 있고, 짧은 시간만 유효한 링크로 전달됩니다.
링크를 복사해 다른 곳에 붙여도 열리지 않고, 로그인하지 않으면 접근할 수 없습니다.

**검색엔진에 뜨나요?**
뜨지 않습니다. 색인을 막아두었습니다.

**제가 누구 프로필에 관심을 눌렀는지 상대가 아나요?**
모릅니다. 관심은 회원님만 봅니다.

## 소개 신청

**같은 분에게 여러 번 신청할 수 있나요?**
진행 중인 신청이 있으면 안 됩니다. 거절이나 취소로 끝난 뒤에는 다시 보낼 수 있습니다.

**상대가 먼저 저에게 신청했는데 제가 또 신청하면요?**
그럴 필요가 없습니다. **시그널 → 받은** 에서 수락하시면 됩니다.

**신청을 취소할 수 있나요?**
상대가 답하기 전이라면 **시그널 → 보낸** 에서 취소할 수 있습니다.

**거절하면 상대가 아나요?**
거절됨으로 표시됩니다. 사유는 남기지 않아도 됩니다.

**수락했는데 왜 바로 연락처가 안 보이나요?**
주선자가 연결을 마쳐야 공개됩니다. 조금만 기다려 주세요.

## 프로필

**제 프로필을 직접 고칠 수 있나요?**
아니요. 주선자에게 알려주시면 수정해드립니다. 사진과 소개도 주선자가 관리합니다.

**잠시 쉬고 싶어요.**
주선자에게 요청하면 목록에서 감춰줍니다(일시중지).

**MBTI나 종교를 안 적어도 되나요?**
됩니다. 필수는 성별·출생연도·거주 지역뿐입니다.

## 주선자용

**AI가 잘못 읽으면요?**
검토 화면에서 모두 고칠 수 있습니다. 신뢰도가 낮거나 빈 항목은 노란색으로 표시됩니다.
확인이 필요한 항목이 남아 있으면 바로 공개할 수 없게 막혀 있습니다.

**AI가 원문에 없는 내용을 지어내나요?**
아니요. 모르는 항목은 비워둡니다. 이름만 보고 성별을 추측하지도 않습니다.

**카카오톡에서 사진과 글을 한 번에 못 가져오면요?**
사진만 올리고 글을 나중에 붙여넣어도 되고, 반대도 됩니다.
글만으로도 대부분의 항목이 채워집니다.

**초대 링크를 다시 보낼 수 있나요?**
프로필 상세에서 다시 발급하면 됩니다. 이전 링크는 그 순간 무효가 됩니다.

**실수로 등록 버튼을 여러 번 눌렀어요.**
프로필은 하나만 생깁니다.

**사진을 지우면 프로필 사진도 사라지나요?**
자동 정리는 프로필이 쓰고 있는 사진을 건드리지 않습니다.
오래 방치된 미등록 가져오기의 원본만 지웁니다.

| 메시지                                   | 뜻과 해결                              |

| 초대된 번호가 아닙니다                   | 주선자에게 등록된 번호 확인            |
| 만료되었거나 이미 사용된 초대 링크입니다 | 새 링크 요청                           |
| 이미 연결된 프로필이 있습니다            | 한 계정에 프로필 하나. 주선자 문의     |
| 이미 진행 중인 신청이 있습니다           | 그 신청이 끝나야 다시 보낼 수 있음     |
| 그 사이 상태가 바뀌었습니다              | 상대가 먼저 처리함. 새로고침           |
| 잠시 후 다시 시도해 주세요               | 인증번호 재요청은 30초 간격            |
| 시도 횟수를 초과했습니다                 | 인증번호 5회 오류. 새로 요청           |
| 링크가 만료되었습니다 (사진)             | 화면을 새로고침하면 사진이 다시 뜹니다 |
